# Security policy | سياسة الأمان

## Reporting a vulnerability

Please report security issues **privately**, never in a public issue or pull request:

- Use **Report a vulnerability** in the [Security tab](https://github.com/darislamtech/darislamtech/security) of this repository, or
- email **darislamtech@gmail.com** with the subject `[Security]`.

Include what you found, the page or file, and the steps to reproduce it. We will reply as soon as we can, fix confirmed issues, and credit you if you wish once the fix is public.

## Scope

The website at [darislamtech.com](https://darislamtech.com) and the code in this repository. The site has no user accounts and stores no personal data.

## الإبلاغ عن ثغرة

أبلغنا عن أي ثغرة أمنية **بشكل خاص**، وليس في Issue أو Pull Request عامة:

- من زر **Report a vulnerability** في [تبويب Security](https://github.com/darislamtech/darislamtech/security) في هذا المستودع، أو
- راسلنا على **darislamtech@gmail.com** وعنوان الرسالة `[Security]`.

اكتب ما وجدته، والصفحة أو الملف، وخطوات إعادة المشكلة. سنرد في أقرب وقت، ونصلح المشكلة المؤكدة، ونذكر اسمك إن أحببت بعد نشر الإصلاح.
