## الهوية

- **التعريف:** منصة تعليمية ودعوية تسعى إلى إعداد علماء ودعاة أصحاب مشاريع دعوية، ومبرمجين وتقنيين يبنون مشاريع تقنية تخدم الإسلام، وتقدّم محتوى تثقيفيًا وتوعويًا وترفيهًا نافعًا.
- **الرسالة:** أن نعلّم المسلمَ ما لا يسعه جهلُه في دينه، والإنسانَ ما لا يسعه جهلُه في التقنية، وأن ننشر الوعي والدعوة بمحتوى نافع، ونبني أدوات ومشاريع تقنية تخدم الإسلام وتيسّر حياة الناس.
- **الرؤية:** جيلٌ من العلماء والدعاة أصحاب المشاريع الدعوية، والمبرمجين والتقنيين الذين يخدمون الإسلام بمشاريع تقنية نافعة، ويشاركون في صناعة المستقبل لا مجرد استهلاك تقنياته.
- **الطموح:** مجتمع يجمع المتخصصين في العلوم الشرعية والدعاة والمبرمجين والمبدعين، يتعاونون على مشاريع دعوية وتقنية نافعة تخدم الإسلام والمسلمين، وينتفع بها كل إنسان.
- **الشعار:** «علمٌ نافع، وتقنيةٌ تصنع الأثر.»
- **الجمهور:** الشباب المسلم، وطلاب العلم الشرعي، والمبرمجون والتقنيون، وأي إنسان مهتم.
- **طريقة الكتابة:** العلم الشرعي والدعوة أولًا ثم التقنية، في كل عنوان وقائمة وترتيب. في الجانب الشرعي نخاطب **المسلم**، وفي الجانب التقني نخاطب **الإنسان**. الأسلوب فصحى مبسّطة قريبة.

## نظرة سريعة

- **ما هو:** موقع مبادرة «دار الإسلام والتقنية» غير الربحية ومفتوحة المصدر.
- **التقنية:** Next.js 16 (App Router)، React 19، TypeScript، Tailwind CSS 4.
- **اللغات:** العربية (الافتراضية) والإنجليزية، كل صفحة تحت `/ar` أو `/en`.
- **الكود:** [github.com/darislamtech/darislamtech](https://github.com/darislamtech/darislamtech)، بترخيص MIT (الكود فقط؛ الاسم والشعار غير مرخَّصين).
- **الدومين والاستضافة:** `darislamtech.com` على Vercel.
