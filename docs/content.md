# إضافة المحتوى وتعديل النصوص

كل المحتوى يُضاف يدويًا في ملفات داخل `src/content/` عبر Pull Request. كل نص يُكتب باللغتين: `{ ar: "...", en: "..." }`. النصوص الطويلة تُفصل فقراتها بسطر فارغ.

## مقال أو خبر — `src/content/posts.ts`
أضف عنصرًا في أول القائمة (الأحدث أولًا):

```ts
{
  slug: "what-is-ai",            // جزء الرابط: /ar/content/what-is-ai
  kind: "article",               // "article" مقال، أو "news" خبر
  date: "2026-11-01",
  title: { ar: "...", en: "..." },
  summary: { ar: "...", en: "..." },
  body: { ar: "فقرة أولى\n\nفقرة ثانية", en: "..." },
  youtubeId: "xxxxxxxxxxx",      // اختياري: فيديو مرتبط
}
```

## فيديو في صفحة المحتوى — `src/content/videos.ts`
`{ youtubeId: "xxxxxxxxxxx", title: { ar: "...", en: "..." } }` — الفيديو يبقى على يوتيوب ويُعرض داخل الموقع.

## الترفيه: فيديوهات وقنوات وكتب — `src/content/entertainment.ts`
صفحات الترفيه الثلاث (`/entertainment` للفيديوهات، و`/entertainment/channels` للقنوات، و`/entertainment/books` للكتب) لها نفس الفئتين (التبويبين): «محتوى ترفيهي تثقيفي» و«محتوى ترفيهي تقني». تحت كل فئة ثلاث قوائم تصنيفات منفصلة: `videos` و`channels` و`books`، فتصنيفات القنوات غير تصنيفات الفيديوهات.

### فيديو
أضف الفيديو في آخر `items` الخاصة بتصنيفه داخل `videos`، مع وقت إضافته:

```ts
videos: [{ id: "music", title: { ar: "الموسيقى والأغاني", en: "Music and songs" }, items: [{ url: "https://youtu.be/xxxxxxxxxxx", added: "2026-11-06T21:30" }] }]
```

- العنوان والصورة المصغّرة وعدد المشاهدات تُجلب من يوتيوب تلقائيًا، بدون وصف.
- `added`: وقت إضافتنا للفيديو. التصنيف الذي أُضيف له آخر فيديو يظهر أولًا في تبويبه، وترتيب «الأحدث» و«الأقدم» يتبع هذا الوقت. «الأكثر مشاهدة» يتبع مشاهدات يوتيوب، وتُجلب عبر YouTube Data API بالمفتاح `YOUTUBE_API_KEY` في إعدادات Vercel (Environment Variables، وليس في الكود). إن لم تتوفر مشاهدات لأي فيديو يختفي زر «الأكثر مشاهدة».
- الروابط المقبولة: `youtu.be/...`، `youtube.com/watch?v=...`، روابط shorts وembed وlive، أو معرّف الفيديو وحده.
- الرابط الخاطئ أو الفيديو المحذوف لا يظهر.

### قناة (يوتيوب فقط)

```ts
channels: [{ id: "programming", title: { ar: "البرمجة", en: "Programming" }, items: [{ url: "https://www.youtube.com/@handle", name: "الاسم كما على القناة" }] }]
```

- الكارت مثل قوائم القنوات في يوتيوب: صورة القناة مدوّرة واسمها كما هو على يوتيوب (نفس الاسم في الصفحتين العربية والإنجليزية)، يُجلبان تلقائيًا. `name` يظهر فقط إذا تعذّرت قراءة صفحة القناة.
- الروابط المقبولة: `youtube.com/@...` (حتى لو الاسم بالعربي)، `youtube.com/channel/...`، `youtube.com/c/...`، `youtube.com/user/...`.
- الرابط الخاطئ أو القناة غير الموجودة أو غير المتاحة على يوتيوب لا تظهر.
- الكارت يفتح القناة على يوتيوب.
- وصف الصفحة في نتائج البحث يذكر أسماء أول 6 قنوات، والصفحة فيها بيانات منظمة (JSON-LD) بقائمة القنوات وروابطها.

### كتاب

```ts
books: [{ id: "programming", title: { ar: "البرمجة", en: "Programming" }, items: [{ title: "Clean Code", cover: "/entertainment/books/clean-code.jpg" }] }]
```

- الكارت: الغلاف واسم الكتاب فقط. الكتب الشرعية يُضاف لها `author` فيظهر المؤلف تحت الاسم.
- `cover`: صورة الغلاف داخل `public/entertainment/books/` (أغلفة الكتب الإنجليزية من Open Library بالـ ISBN: `covers.openlibrary.org`). بدونه يظهر غلاف بسيط بلون الموقع مكتوب عليه اسم الكتاب.
- الكتاب يظهر بدون رابط.

### التصنيفات والفئات
- **مين يختار التصنيف:** المالك يرسل القناة أو الكتاب أو الفيديو، والمنفّذ يضعه في التصنيف المناسب، وإن لم يوجد تصنيف مناسب ينشئ تصنيفًا جديدًا.
- **تصنيف جديد:** عنصر `{ id, title: { ar, en }, items: [] }` داخل `videos` أو `channels` أو `books` في الفئة المطلوبة.
- التصنيف الفارغ يعرض «لم نُضف … بعد». الفئة التي ليس فيها تصنيفات لنوع ما تعرض الجملة مرة واحدة.
- **فئة جديدة (تبويب):** عنصر `{ id, title: { ar, en }, videos: [], channels: [], books: [] }`. أول فئة في القائمة هي الافتراضية.

## منتج — `src/content/products.ts`

```ts
{
  slug: "dar-hifz",
  status: "inDevelopment",       // available | inDevelopment | comingSoon | idea
  name: { ar: "...", en: "..." },
  summary: { ar: "...", en: "..." },
  description: { ar: "...", en: "..." },
  url: "https://...",            // اختياري: رابط المنتج
  repoUrl: "https://github.com/...", // اختياري: الكود المصدري
  youtubeId: "xxxxxxxxxxx",      // اختياري: فيديو تعريفي
  installSteps: { ar: ["...", "..."], en: ["...", "..."] }, // اختياري: التثبيت على الهاتف
}
```

لا يُعلَّم منتج بـ `available` قبل إطلاقه فعليًا.

## برنامج تعلّم — `src/content/learn.ts`
البرنامج مقسّم سنوات، وكل سنة فيها مسارات:

```ts
{
  id: "foundation",
  title: { ar: "السنة الأولى: سنة تأسيسية", en: "..." },
  description: { ar: "مسار واحد للجميع.", en: "..." },
  tracks: [{ id: "foundation", title: { ar, en }, description: { ar, en } }],
}
```

القسم كله «تحت الإنشاء» حتى توجد مادة تعليمية حقيقية. أيقونة ولون كل مسار يُحدَّدان حسب `id` في `src/app/[lang]/learn/page.tsx`.

## نصوص الواجهة
كل نصوص الصفحات والأزرار في `src/i18n/dictionaries/ar.json` و`en.json`. الملفان بنفس الشكل تمامًا؛ أي نص يُضاف أو يُعدّل في الاثنين.

**مواضيع صفحة المحتوى:** في `topics` داخل الملفين، وهي مجموعتان بالترتيب: المواضيع الدينية والدعوية ثم المواضيع التقنية، ولكل مجموعة `title` و`items`. موضوع جديد = عنصر جديد في `items` بالعربي والإنجليزي.

## البريد وحسابات التواصل
في `src/config/site.ts`، ومعها القائمة في [accounts.md](accounts.md) تُحدَّث في نفس التعديل. لا يُضاف إلا حساب موجود فعلًا.

## طرق الدعم المادي (صفحة «ادعمنا»)
في `supportLinks` داخل `src/config/site.ts`، مثلًا `{ name: "Ko-fi", href: "https://ko-fi.com/..." }` أو `{ name: "PayPal", href: "https://paypal.me/..." }`. القائمة فارغة الآن، فتعرض الصفحة «نجهّز طرق الدعم المادي». لا يُضاف رابط قبل أن يكون الحساب مفعّلًا.

## المحتوى الشرعي
الآيات والأذكار والأحكام لا تُضاف إلا من مصادر موثوقة وبمراجعة مؤهلين.
